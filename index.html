Open source

Five tools, each with a reason to exist.

PHP · Swoole · Feb 2026

KQueue

Laravel's queue worker runs one job at a time. KQueue gives every job its own coroutine, so thousands run concurrently on a single thread with no changes to existing job code. Like a loom weaving many threads on one frame.

View on GitHub

Go · Jan 2025

GateSSH

One gateway for every SSH and SFTP login. It routes each connection to the right container, pod or private server through an API or MySQL, with per-target IP allow and deny lists. Your infrastructure is never exposed directly.

View on GitHub

Node.js

imap-smtp

A complete mail server in modular Node.js. It sends over SMTP, serves mailboxes over IMAP and delivers locally over LMTP, with an outgoing queue, bounce tracking, dynamic IP selection and a web dashboard.

View on GitHub

JavaScript · Docker Swarm · Consul

Nomad Overlay Network

Containers that Nomad placed on different hosts couldn't reach each other. This service attaches them to a Swarm overlay network and keeps their Consul DNS records in sync, automatically.

View on GitHub

Go

pvm

Install and switch PHP versions on Linux without root. Pre-built PHP comes from GitHub Releases, and one small file decides which version runs. No shell hacks.

View on GitHub
